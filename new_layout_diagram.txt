BEHAVIOR:
• All buttons send commands directly via SerialManager.port.write()
• CRC16 calculated automatically using ModbusRTU.crc16()
• No response waiting or parsing
• Status bar updates:
  - "Normal command sent"
  - "Bypass command sent"
  - "Switch command sent: Inverter"
  - "Reset command sent"
  - "Reset Def command sent"
• Error dialogs on failure
• Buttons styled with BTN_SECONDARY_BG (Deep Blue) / BTN_SECONDARY_HOVER (Mist Blue)
• Consistent theme: rounded corners, borders, dark panel backgrounds
• RD Panel uses horizontal layout with stretch to push controls left
• Reset Panel uses vertical layout with two stacked buttons
