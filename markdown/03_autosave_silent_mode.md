# 🧩 03 Memory Auto-Save — Silent & Stateless Mode

---

## 🌟 專案目標  
讓使用者在修改任何 03 位址時，
程式**自動即時儲存**設定到 `./setting/03memory_setting.dmem`，
全程靜默、無狀態列提示、無訊息框、無錯誤紀錄。  

以「使用者完全無感」為核心設計原則。

---

## 📁 專案結構  

```
project_root/
├─ app.py
├─ setting/
│   └─ 03memory_setting.dmem
```

---

## 🗋 設定檔格式  

- 純文字，每行一個十進位位址。  
- 允許空行與 `#` 註解。  
- 依行序對應到 UI 的位址欄位。  

**範例：**
```
0
2
8
85
125
120
50
80
70
55
```

---

## ⚙️ 系統行為  

### 🟢 啟動階段
1. 程式啟動時自動讀取 `03memory_setting.dmem`。  
2. 找不到檔案 → 自動建立並填入預設值（全部 0）。  
3. 值超出上限 → 自動夾限到最大值（例如 9999）。  
4. 不顯示任何訊息或狀態列。  

---

### 🟢 運行階段
1. 使用者修改任一 03 位址欄位（例如離開焦點、輸入結束）。  
2. 系統自動觸發「延遲 300–500ms 的自動儲存」。  
3. 在背景完成寫入，不影響 UI。  
4. 無提示、無記錄、無重繪。  
5. 下一次開啟程式即載入最新值。  

---

### 🟢 關閉程式
- 不需額外保存步驟。  
- 最後一次自動儲存結果即為最終狀態。  

---

## ⚡ 設計重點  

| 項目 | 行為 |
|------|------|
| 寫入方式 | 非同步／延遲合併寫入 |
| 寫入策略 | 直接覆蓋原檔，無備份、無暫存 |
| 狀態提示 | 無（完全靜默） |
| 錯誤處理 | 無錯誤記錄、無訊息視窗 |
| 檔案保證 | 由系統 I/O 層自然覆蓋，若寫入中斷則下次重新建立 |
| 範圍控制 | 自動 clamp 值在 0 ~ MAX_ADDR_03 |
| 頻率控制 | 多次修改會合併為一次寫入，避免頻繁 I/O |

---

## 🧠 自動保存流程圖  

```
使用者修改位址 → 啟動0.5秒延遲 → 無其他修改 → 寫入檔案
             ↑                                       ↓
             │                                       完成
             └─ 若在0.5秒內又修改 → 延後計時 (只寫一次)
```

---

## 💡 設計理念  

> **永不打擾使用者**  
> - 無對話框  
> - 無提示文字  
> - 無狀態更新  
> - 無錯誤紀錄  
>   
> **永遠保持最新設定**  
> - 每次修改都自動保存  
> - 重新開啟程式即載入最後設定

## ✅ 最終行為特性  

| 特性 | 說明 |
|------|------|
| 開啟程式 | 自動載入設定檔 |
| 修改欄位 | 0.5秒後自動保存 |
| 顯示行為 | 完全靜默、無提示 |
| 檔案狀態 | 永遠同步最新值 |
| 超出範圍 | 自動夾限，不報錯 |
| 使用體驗 | 無感保存、不影響操作流暢度 |

## 🧩 適用場景  

- 工控、測試監控等需要穩定自動保存的應用  
- 不希望任何 UI 通知干擾操作的介面  
- 多人共用、長期執行的監控系統  

---

**此設計確保：**  
- 所有變更自動保存、無需手動操作。  
- 不記錄錯誤、不顯示提示、不打擾使用者。  
- 設定檔始終保持最新、合法、安全。
